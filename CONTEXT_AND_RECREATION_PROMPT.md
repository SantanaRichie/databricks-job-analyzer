### Purpose of the Tool
The primary purpose of the Databricks Job Analyzer is to give insights into job performance, detect bottlenecks, and improve efficiency. The tool provides a graphical user interface (GUI) that allows users to easily visualize job metrics and analyze execution times.

### Features
- **Job Performance Tracking**: Monitor job execution times and resource utilization.
- **Bottleneck Detection**: Identify steps in the job that may be delaying execution.
- **Custom Alerts**: Set up alerts based on specific performance thresholds.
